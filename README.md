# Predicting F1 Pit Stops

This project predicts whether a Formula 1 driver will make a pit stop on the next lap using data from the Kaggle Playground Series - Season 6 Episode 5 competition.

The goal is to build a clean, explainable machine learning workflow that goes beyond a basic Kaggle submission. This project focuses on data understanding, exploratory analysis, feature engineering, model evaluation, and practical interpretation of results.

## Project Goal

In Formula 1, pit stop timing is a key part of race strategy. This project frames pit stop prediction as a binary classification problem:

> Will a driver pit on the next lap?

By analyzing race, lap, driver, and strategy-related features, the model attempts to identify patterns that may signal an upcoming pit stop.

## Dataset

The data comes from the Kaggle Playground Series - Season 6 Episode 5 competition: **Predicting F1 Pit Stops**.

Due to Kaggle competition rules, the raw dataset is not included in this repository. To reproduce the project, download the data directly from Kaggle and place it in the appropriate working environment.
